## 🎉 First Open-Source Release

SmartGarbage Chintalavalasa — an open-source waste management portal for Indian municipalities.

### ✨ Features

- **Waste Collection Schedules** — Check pickup times for 5 wards
- **Missed Pickup Reporting** — GPS + photo evidence
- **Ward Transparency Dashboards** — Live bin fill levels
- **Green Points** — Civic incentive program
- **PAYT Billing** — Weight-based waste disposal
- **Bilingual** — English + Telugu
- **PWA** — Offline support, installable as app
- **Dark Mode** — User-selectable theme
- **Font Scaling** — A- A A+ accessibility
- **High Contrast** — Toggle for low-vision users
- **Search Autocomplete** — 16 entries with keyboard nav
- **Mega Menu** — WCAG 2.1 AA compliant
- **Service Worker** — 3-tier caching, instant repeat visits
- **Open Data API** — JSON transparency endpoint
- **llms.txt** — AI crawler guidance

### 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Backend | Python 3.11+, Flask |
| Database | PostgreSQL (Supabase) |
| Frontend | Bootstrap 5, Leaflet.js, Chart.js |
| ML | scikit-learn |
| Deployment | Docker, Render |
| Testing | pytest |

### 📦 Installation

```bash
git clone https://github.com/jaganmohan08112005-sketch/SmartgarbageCSP.git
cd SmartGarbage
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
flask db upgrade
python run.py
```
