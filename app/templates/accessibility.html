♿ Accessibility Statement

Our commitment

The SmartGarbage Chintalavalasa portal is committed to making this website accessible to all users, including people with disabilities. We follow the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA and the Guidelines for Indian Government Websites.

What we have done

  • Skip to content link — keyboard users can bypass navigation
  • Keyboard navigation — all interactive elements are reachable and operable via keyboard
  • Screen reader support — semantic HTML, ARIA labels, and a documented 40+ heading structure with numbered sections (see Page structure and headings below)
  • Colour contrast — all text meets WCAG AA contrast ratios (4.5:1 for body text)
  • Focus indicators — visible focus outlines on all interactive elements
  • Text resize — the portal supports up to 200% zoom without loss of content
  • Dark mode — high-contrast dark theme with maintained contrast ratios
  • High contrast mode — additional high-contrast toggle for users with low vision
  • Alt text — all meaningful images include descriptive alternative text
  • Form labels — all form inputs have associated labels for screen readers
  • Language declaration — HTML lang attribute set to English with Telugu alternative
  • Mobile responsive — fully responsive design for all screen sizes

Page structure and headings

Every page uses a single <h1> page title, followed by <h2> sections and <h3> numbered subsections — with no skipped levels — so screen-reader users can navigate by heading and jump directly to the content they need. The homepage alone provides 41 headings (1 h1, 12 h2, 28 numbered h3), in line with GOV.UK's deep heading practice for long public pages.

Heading outline of the homepage:

  • 1. Overview of the service — 1.1 About this service · 1.2 What you can use this service for · 1.3 About the organisation
  • 2. Services available on this portal — 2.1 Collection schedule · 2.2 Report a missed or partial pickup · 2.3 Ward transparency dashboard · 2.4 Track a complaint · 2.5 Environmental impact data · 2.6 Local weather
  • 3. How to get help — 3.1 Urgent emergencies · 3.2 If you cannot use this online service · 3.3 Contact the Directorate
  • 4. Service statistics — 4.1 Wards covered · 4.2 Residents served · 4.3 Complaints resolved · 4.4 Average resolution time
  • 5. Community impact and updates — 5.1 Environmental impact · 5.2 Latest notices and advisories
  • 6. Frequently asked questions — 6.1 Schedules · 6.2 Reporting problems · 6.3 Green Points · 6.4 Wards and coverage
  • 7. Popular services (quick links, no subsections)
  • 8. About this service — 8.1 Who runs this service · 8.2 Data protection and privacy · 8.3 Accessibility commitment · 8.4 Tell us how we can improve

Navigation landmarks (header menu, footer columns) use their own headings and are separated from main content, so heading navigation stays focused on page content.

Compatibility

This website is designed to be compatible with:

  • All modern browsers (Chrome, Firefox, Safari, Edge)
  • Screen readers (NVDA, JAWS, VoiceOver, TalkBack)
  • Mobile devices (iOS and Android)
  • Desktop and tablet displays
